# 🏦 Apex Bank Management System

A modern and responsive **Bank Management System Frontend** built using **HTML5, CSS3, and Vanilla JavaScript**. This project simulates a real-world banking dashboard with customer management, account operations, transactions, analytics, and authentication interfaces.

## 🌐 Live Demo

🔗 https://epam-proj-2026-55d22av3g-nitin962devs-projects.vercel.app

---

## ✨ Features

- 🔐 Secure Login & Registration
- 📊 Interactive Financial Dashboard
- 👥 Customer Management
- 💳 Account Management
- 💰 Deposit & Withdrawal
- 🔄 Fund Transfer
- 📜 Transaction History
- 💵 Loan & EMI Calculator
- 💳 Credit & Debit Cards
- 📈 Reports & Analytics
- 👤 User Profile
- ⚙️ System Settings
- 🌙 Dark / Light Theme
- 📱 Fully Responsive Design

---

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript (ES6)
- Chart.js
- Font Awesome
